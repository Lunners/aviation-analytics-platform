Hong Kong Aviation Analytics Platform
Overview
This project collects real-time aircraft data from the OpenSky Network API and stores it in a PostgreSQL database hosted on Supabase.

The data is transformed and visualized in Power BI to provide insights into aviation traffic around Hong Kong.

Technology Stack
Python
OpenSky API
PostgreSQL (Supabase)
Power BI

Project Architecture
OpenSky API ↓ Python ETL ↓ Supabase PostgreSQL ↓ Power BI Dashboard
